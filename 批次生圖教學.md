## 3. 設定檔說明（config.txt）

`config.txt` 用來填入可選的第三方 API Token。**目前腳本預設只使用 Pollinations.ai（免費），可跳過此步驟。**

```ini
# ============================================================
#  批次生圖設定檔
#  說明：把 Token 填入等號後面即可，不需要加引號
#  沒有的平台留空，腳本會自動跳過
# ============================================================

# ── 平台 1：Hugging Face（免費額度，每日可重置）
# 取得方式：https://huggingface.co/settings/tokens → New token → Read
HF_TOKEN=你的token填這裡

# ── 平台 2：Together AI（免費 $5 額度）
TOGETHER_TOKEN=

# ── 平台 3：Fal.ai（免費額度）
FAL_TOKEN=

# ============================================================
#  Pollinations.ai 完全免費，無需 Token，腳本自動使用
# ============================================================
```

腳本中讀取此檔的函式：

```python
def load_config():
    cfg = {}
    p = Path(__file__).parent / "config.txt"
    if p.exists():
        for line in p.read_text(encoding="utf-8").splitlines():
            line = line.strip()
            if line and not line.startswith("#") and "=" in line:
                k, v = line.split("=", 1)
                cfg[k.strip()] = v.strip()
    return cfg
```

**說明：** 讀取同目錄下的 `config.txt`，逐行解析 `KEY=VALUE` 格式，忽略以 `#` 開頭的註解行。

## 4. 提示詞清單說明（提示詞清單.txt）

### 格式規則

```
# ============================================================
#  提示詞清單 v4.0
#  格式：### 主題：分類名稱 作為標題，下方每行一個場景
# ============================================================

### 主題：賽博龐克 (Cyberpunk)
A cinematic wide shot of a neon-lit cyberpunk city street at night, heavy rain...
Close up portrait of a female hacker with electric blue neon hair...

### 主題：奇幻魔幻 (Fantasy)
An ancient stone temple overgrown with glowing magical vines...
A female elf warrior standing on a cliff edge at golden hour...

### 主題：科幻太空 (Sci-Fi)
A massive space station orbiting a ringed gas giant...
```

| 規則 | 說明 |
|------|------|
| `### 主題：XXX` | 宣告一個新主題分類，圖片會存入對應子資料夾 |
| 每行一條英文描述 | 即一個獨立的生圖提示詞（Prompt） |
| `#` 開頭 | 註解行，不執行 |
| 空白行、`-`、`*`、`\|`、`=` 開頭 | 自動略過 |

### 好的提示詞範例

```
A cyberpunk city at night, neon lights, rainy street, reflections on wet pavement, 8k, masterpiece
A peaceful mountain lake at sunrise, soft mist, reflection, photorealistic, ultra detailed
An ancient dragon sleeping on a hoard of gold in a massive cavern, cinematic lighting
```

> **建議用英文撰寫**，Pollinations.ai 對英文的理解品質遠優於中文。

## 5. 主程式解析（批次生圖.py）

### 5.1 全域設定區

```python
PROMPT_FILE    = "提示詞清單.txt"  # 提示詞檔案名稱
OUTPUT_DIR     = "生成圖片"        # 圖片輸出資料夾
WIDTH          = 1024              # 圖片寬度（像素）
HEIGHT         = 576               # 圖片高度（像素）
STEPS          = 4                 # 生成步數（Pollinations 忽略此值）
MAX_RETRY      = 3                 # 單張圖最多重試次數
SLEEP_BETWEEN  = 3                 # 每張圖之間的間隔秒數
```

可依需求直接修改這些數值，例如把尺寸改為 `1920 x 1080`。

---

### 5.2 圖片生成器（PollinationsProvider）

```python
class PollinationsProvider:
    name = "Pollinations.ai (免費)"

    def available(self, cfg):
        return True  # 永遠可用，不需 Token

    def generate(self, prompt):
        seed = random.randint(1, 99999)          # 每次隨機種子，確保圖片不重複
        encoded = urllib.parse.quote(prompt)      # URL 編碼提示詞
        url = (
            f"https://image.pollinations.ai/prompt/{encoded}"
            f"?width={WIDTH}&height={HEIGHT}&model=flux&nologo=true&seed={seed}"
        )
        r = requests.get(url, timeout=180)        # 最多等 3 分鐘
        if r.status_code == 200 and r.headers.get("content-type", "").startswith("image"):
            return r.content, None               # 回傳圖片二進位資料
        return None, f"HTTP {r.status_code}"     # 回傳錯誤訊息
```

**運作原理：**  
直接對 `https://image.pollinations.ai/prompt/...` 發送 GET 請求，伺服器會回傳一張 PNG 圖片。使用 `flux` 模型，完全免費。

### 5.3 容錯機制（generate_with_fallback）

```python
def generate_with_fallback(prompt, cfg, index, total):
    for attempt in range(MAX_RETRY):              # 最多重試 MAX_RETRY 次
        active = get_active_providers(cfg)
        if not active:
            time.sleep(300)                       # 沒有可用 Provider，等 5 分鐘
            continue
        for provider in active:
            try:
                img, err = provider.generate(prompt)
                if img:
                    return img, provider.name     # 成功，回傳圖片
                if err and "QUOTA" in str(err):
                    disable_provider(provider.name, seconds=3600)  # 超配額，停用 1 小時
            except Exception:
                pass
        if attempt < MAX_RETRY - 1:
            time.sleep(15)                        # 重試前等 15 秒
    return None, None                             # 全部失敗
```

**說明：** 自動重試失敗的請求，若遇到配額耗盡則暫時停用該 Provider，保證腳本不因單次失敗而中斷。

### 5.4 讀取提示詞（load_prompts）

```python
def load_prompts(filepath):
    path = Path(filepath)
    if not path.exists():
        print(f"找不到提示詞檔案：{filepath}")
        sys.exit(1)

    prompts = []
    current_category = "其他主題"               # 預設分類

    with open(path, "r", encoding="utf-8") as f:
        for line in f:
            stripped = line.strip()
            # 略過空行與分隔符號
            if not stripped or stripped.startswith(("-", "*", "|", "=")):
                continue
            # 解析主題標題
            if stripped.startswith("### 主題："):
                current_category = stripped.replace("### 主題：", "").strip()
                continue
            elif stripped.startswith("#"):
                continue
            # 清除引號前綴
            prompt = stripped.lstrip(">").strip()
            if prompt:
                prompts.append((current_category, prompt))  # (分類, 提示詞)

    return prompts
```

回傳格式為 `[(分類, 提示詞), ...]` 的列表。

### 5.5 存檔（save_image）

```python
def save_image(img_bytes, prompt, idx, output_dir, provider, category="其他"):
    ts = datetime.now().strftime("%Y%m%d_%H%M%S")       # 時間戳
    safe = "".join(
        c for c in prompt[:28] if c.isalnum() or c in " _-"
    ).strip().replace(" ", "_")                          # 提示詞前 28 字（安全化）

    fname = f"{idx:03d}_{ts}_{safe}_1.png"

    # 移除 Windows 不合法路徑字元
    safe_category = "".join(
        c if c not in '\\/*?:"<>|' else "-" for c in category
    )

    cat_dir = Path(output_dir) / safe_category           # 依分類建立子資料夾
    cat_dir.mkdir(parents=True, exist_ok=True)
    fpath = cat_dir / fname
    with open(fpath, "wb") as f:
        f.write(img_bytes)

    return str(fpath)
```

**檔名範例：**
```
001_20260516_143022_A_cinematic_wide_shot_of_a_1.png
│   │              │
│   時間戳記       提示詞前28字（底線取代空格）
序號
```

### 5.7 完整程式碼

```python
import requests
import json
import io
import os
import time
import sys
import random
import urllib.parse
from datetime import datetime
from pathlib import Path

# 強制 UTF-8 輸出（Windows 中文環境必備）
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding="utf-8", errors="replace")
sys.stderr = io.TextIOWrapper(sys.stderr.buffer, encoding="utf-8", errors="replace")

PROMPT_FILE    = "提示詞清單.txt"
OUTPUT_DIR     = "生成圖片"
WIDTH          = 1024
HEIGHT         = 576
STEPS          = 4
MAX_RETRY      = 3
SLEEP_BETWEEN  = 3


def load_config():
    cfg = {}
    p = Path(__file__).parent / "config.txt"
    if p.exists():
        for line in p.read_text(encoding="utf-8").splitlines():
            line = line.strip()
            if line and not line.startswith("#") and "=" in line:
                k, v = line.split("=", 1)
                cfg[k.strip()] = v.strip()
    return cfg


class PollinationsProvider:
    name = "Pollinations.ai (免費)"

    def available(self, cfg):
        return True

    def generate(self, prompt):
        seed = random.randint(1, 99999)
        encoded = urllib.parse.quote(prompt)
        url = (
            f"https://image.pollinations.ai/prompt/{encoded}"
            f"?width={WIDTH}&height={HEIGHT}&model=flux&nologo=true&seed={seed}"
        )
        r = requests.get(url, timeout=180)
        if r.status_code == 200 and r.headers.get("content-type", "").startswith("image"):
            return r.content, None
        return None, f"HTTP {r.status_code}"


PROVIDERS = [PollinationsProvider()]
_provider_disabled = {}


def get_active_providers(cfg):
    now = time.time()
    return [p for p in PROVIDERS if p.available(cfg) and _provider_disabled.get(p.name, 0) < now]


def disable_provider(name, seconds=300):
    _provider_disabled[name] = time.time() + seconds


def generate_with_fallback(prompt, cfg, index, total):
    for attempt in range(MAX_RETRY):
        active = get_active_providers(cfg)
        if not active:
            time.sleep(300)
            continue
        for provider in active:
            try:
                img, err = (
                    provider.generate(prompt)
                    if isinstance(provider, PollinationsProvider)
                    else provider.generate(prompt, cfg)
                )
                if img:
                    return img, provider.name
                if err and "QUOTA" in str(err):
                    disable_provider(provider.name, seconds=3600)
            except Exception:
                pass
        if attempt < MAX_RETRY - 1:
            time.sleep(15)
    return None, None


def load_prompts(filepath):
    path = Path(filepath)
    if not path.exists():
        print(f"找不到提示詞檔案：{filepath}")
        sys.exit(1)
    prompts = []
    current_category = "其他主題"
    with open(path, "r", encoding="utf-8") as f:
        for line in f:
            stripped = line.strip()
            if not stripped or stripped.startswith(("-", "*", "|", "=")):
                continue
            if stripped.startswith("### 主題："):
                current_category = stripped.replace("### 主題：", "").strip()
                continue
            elif stripped.startswith("#"):
                continue
            prompt = stripped.lstrip(">").strip()
            if prompt:
                prompts.append((current_category, prompt))
    return prompts


def save_image(img_bytes, prompt, idx, output_dir, provider, category="其他"):
    ts = datetime.now().strftime("%Y%m%d_%H%M%S")
    safe = "".join(c for c in prompt[:28] if c.isalnum() or c in " _-").strip().replace(" ", "_")
    fname = f"{idx:03d}_{ts}_{safe}_1.png"
    safe_category = "".join(c if c not in '\\/*?:"<>|' else "-" for c in category)
    cat_dir = Path(output_dir) / safe_category
    cat_dir.mkdir(parents=True, exist_ok=True)
    fpath = cat_dir / fname
    with open(fpath, "wb") as f:
        f.write(img_bytes)
    return str(fpath)


def save_log(entries, output_dir):
    ts = datetime.now().strftime("%Y%m%d_%H%M%S")
    p = Path(output_dir) / f"生成記錄_{ts}.json"
    with open(p, "w", encoding="utf-8") as f:
        json.dump(entries, f, ensure_ascii=False, indent=2)


def main():
    cfg = load_config()
    print("=" * 60 + "\n  批次生圖腳本 v3.1 ─ 防呆強化版\n" + "=" * 60)
    original_prompts = load_prompts(PROMPT_FILE)

    if not original_prompts:
        print(f"\n❌ 找不到任何提示詞，請檢查 {PROMPT_FILE} 檔案。")
        return

    from collections import Counter
    cat_counts = Counter(cat for cat, _ in original_prompts)
    unique_cats = list(dict.fromkeys(cat for cat, _ in original_prompts))

    print("\n" + "=" * 60 + "\n  📋 發現以下提示詞主題：")
    for i, cat in enumerate(unique_cats, 1):
        print(f"  [{i}] {cat} (共 {cat_counts[cat]} 條)")
    print(f"  [0] 生成全部 (共 {len(original_prompts)} 條)\n" + "=" * 60)

    choice = input("\n👉 請輸入要生成的主題編號 (可用逗號多選，輸入 0 代表全部): ").strip().replace("，", ",")

    prompts_to_generate = original_prompts

    if choice and choice != "0":
        try:
            selected_cats = []
            for x in choice.split(","):
                x = x.strip()
                if x:
                    cat_idx = int(x)
                    if 1 <= cat_idx <= len(unique_cats):
                        selected_cats.append(unique_cats[cat_idx - 1])
                    else:
                        print(f"  ⚠️ 警告：找不到主題編號 [{cat_idx}]，已略過。")

            if not selected_cats:
                print("\n❌ 未選擇有效的主題，將自動切換為【生成全部】...")
            else:
                prompts_to_generate = [(cat, p) for cat, p in original_prompts if cat in selected_cats]
                print(f"\n✅ 已選擇主題: {', '.join(selected_cats)}")

                print("\n" + "=" * 60 + "\n  📜 該主題下的提示詞清單：")
                for i, (c, p) in enumerate(prompts_to_generate, 1):
                    preview = p[:60] + "..." if len(p) > 60 else p
                    print(f"  [{i}] {preview}")
                print(f"  [0] 全部生成 (共 {len(prompts_to_generate)} 條)\n" + "=" * 60)

                sub_choice = input("\n👉 請輸入要生成的【提示詞編號】 (可用逗號多選，輸入 0 代表全選): ").strip().replace("，", ",")

                if sub_choice and sub_choice != "0":
                    sub_indices = []
                    for x in sub_choice.split(","):
                        x = x.strip()
                        if x:
                            p_idx = int(x)
                            if 1 <= p_idx <= len(prompts_to_generate):
                                sub_indices.append(p_idx)
                            else:
                                print(f"  ⚠️ 警告：找不到提示詞編號 [{p_idx}]，已略過。")

                    if sub_indices:
                        prompts_to_generate = [prompts_to_generate[i - 1] for i in sub_indices]
                        print(f"\n✅ 已精準選擇 {len(prompts_to_generate)} 條特定提示詞。")
                    else:
                        print("\n❌ 未選擇有效的提示詞，將自動切換為【該主題全選】...")

        except Exception as e:
            print(f"\n❌ 輸入格式嚴重錯誤，將自動切換為【生成全部】...")
            prompts_to_generate = original_prompts

    total = len(prompts_to_generate)
    if total == 0:
        print("沒有要生成的提示詞，程式結束。")
        return

    print(f"\n📁 預計生成：{total} 條\n" + "─" * 60 + "\n  開始批次生圖 (按 Ctrl+C 中斷)\n" + "─" * 60)

    out = Path(OUTPUT_DIR)
    out.mkdir(exist_ok=True)
    entries, ok, fail, t0 = [], 0, 0, time.time()

    for idx, (category, prompt) in enumerate(prompts_to_generate, 1):
        print(f"\n[{idx}/{total}] [{category}] {prompt[:50]}...")
        img, provider_used = generate_with_fallback(prompt, cfg, idx, total)
        entry = {
            "index": idx,
            "category": category,
            "prompt": prompt,
            "status": "success" if img else "failed",
        }
        if img:
            entry["file"] = save_image(img, prompt, idx, out, provider_used, category)
            print(f"  💾 存檔：{Path(entry['file']).parent.name}/{Path(entry['file']).name}")
            ok += 1
        else:
            fail += 1
        entries.append(entry)
        if idx < total:
            time.sleep(SLEEP_BETWEEN)

    save_log(entries, out)
    print("\n" + "=" * 60 + f"\n  完成！成功 {ok} 張 | 失敗 {fail} 張\n" + "=" * 60)


if __name__ == "__main__":
    try:
        main()
    except KeyboardInterrupt:
        sys.exit(0)
```

## 7. 互動選單操作說明

執行後會出現**兩層選單**：

### 第一層：選擇主題

```
============================================================
  📋 發現以下提示詞主題：
  [1] 賽博龐克 (Cyberpunk) (共 20 條)
  [2] 奇幻魔幻 (Fantasy) (共 20 條)
  [3] 科幻太空 (Sci-Fi) (共 10 條)
  [0] 生成全部 (共 50 條)
============================================================

👉 請輸入要生成的主題編號 (可用逗號多選，輸入 0 代表全部):
```

| 輸入範例 | 效果 |
|----------|------|
| `0` | 生成所有主題的全部提示詞 |
| `1` | 只生成主題 1（賽博龐克） |

## 9. 常見問題

**Q：執行後顯示「找不到提示詞檔案」**  
A：確認 `提示詞清單.txt` 與 `批次生圖.py` 放在同一個資料夾。

**Q：圖片生成失敗，全部 status 都是 failed**  
A：可能是網路問題或 Pollinations.ai 暫時壅塞。等幾分鐘後重試，或檢查網路連線。

**Q：想中途停止**  
A：按 `Ctrl + C`，已生成的圖片不受影響。

**Q：圖片存到哪裡？**  
A：腳本同目錄下的 `生成圖片/` 資料夾，依主題自動分類。

**Q：Windows 顯示亂碼**  
A：腳本已在開頭強制設定 UTF-8 輸出，若仍亂碼可在 cmd 中執行 `chcp 65001` 後再執行腳本。

**Q：如何加快速度？**  
A：調小 `SLEEP_BETWEEN`（如改為 `1`），但太快可能被 Pollinations 限流。

**Q：如何改變圖片尺寸？**  
A：修改腳本開頭的 `WIDTH` 和 `HEIGHT`，例如改成 `1920` 和 `1080`。

### 睡前開著讓它跑

由於 Pollinations.ai 的生成速度大約每張 10~30 秒（視伺服器負載），100 條提示詞約需 30~60 分鐘。睡前執行，隔天起來就有一堆圖可挑。
